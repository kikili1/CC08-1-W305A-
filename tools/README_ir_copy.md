# CC08-1 两键红外快速复制

## 操作

- 母机：OK＋7 同时按住 3 秒进入，红灯常亮；松开后单按 OK 自动发送两段。
- 子机：OK＋9 同时按住 2.5 秒进入，红灯常亮；松开后自动顺序学习到 S1、S2。
- 两端均单按返回退出。进入组合键必须完全松开，才能开始发送。
- 母机无操作 30 分钟退出；每次新按下非返回键刷新计时，持续按住不刷新。
- 子机从最后一次按键动作（按下或松开）或红外接收活动开始计时，无操作 8 秒退出；按键状态不变的持续按住不反复刷新。单按返回仍立即退出。接收失败后常亮并重新等待 8 秒。

## 收发方式

母机按键位顺序播放已学习的红外波形，空槽发送专用波形标记。母机和子机都应使用新版固件。

| 母机已学习的键 | 第一段 | 第二段 |
|---|---|---|
| S1、S2 | S1 | S2 |
| 仅 S1 | S1 | 清除 S2 的标记 |
| 仅 S2 | 清除 S1 的标记 | S2 |
| 无 | 不发送 | 不发送 |

学习波形发送首帧一次、重复段两次；整个帧重复的码型则发送三帧。时长由学习记录决定。空槽标记只发送一次。

第三个周期在最后一个载波脉冲结束处停止。第一段停止后留 300 ms 静默，再发送第二段。发送时闪灯，发完母机常亮，可重复操作。

子机用连续 200 ms 无脉冲划分两段，完成第一段后才切换到第二段。支持首帧与短重复码不同，以及三帧完整码。原始采集容量为三倍单槽波形长度，压缩后仍保存为普通学习记录，可继续使用原有按键回放。

两段均确认后，先写入有效学习记录，再清除有空槽标记的键位，完成后灭灯退出。失败时丢弃本轮临时结果。第一段结束确认后，400 ms 内未捕获第二段则判本轮失败，重新开始 8 秒等待。

## 边界与风险

- 学习格式沿用最多 6 类载波时长、6 类空闲时长及 76 项压缩波形。无法匹配重复段、采集溢出或数据不完整时失败，不写入。
- 固定 300 ms 分段不能覆盖任意长停顿。母机检查实际播放范围，拒绝载波段或码内空闲达到 200 ms 的记录；要支持这类码型需重新设计分段门限。
- 母机常亮只代表发送结束；子机灭灯才代表学习保存成功。
- 接收失败不会修改旧记录。写入失败可能已更新其中一个槽；两个槽写入不具备断电原子性，需重新复制。
- 低于 2100 mV 时不保存。载波频率、引脚及发送补偿沿用现有红外驱动。

`test_ir_copy.py` 使用主机 GCC 编译实际状态机和发送驱动函数，仅替换 SDK 接口。临时文件在测试结束后自动删除。

```text
python tools/test_ir_copy.py --cc <gcc.exe 路径>
```

检查覆盖单键按原键位复制和清除另一槽、空槽标记损坏、漏收第二段、双键顺序、完整帧/短重复码、最大长度、300 ms 间隔、保存失败、低电压、退出及超时。

已通过离线检查、pi32 编译链接和 package-only 打包。链接提示现有陀螺库 pi32v2/pi32 架构不一致；打包工具提示当前布局的 BLE RCSP 升级空间不足，不应把生成结果视为该升级通道已验证。
